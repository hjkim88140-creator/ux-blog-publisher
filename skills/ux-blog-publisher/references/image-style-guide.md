# 블로그 에디토리얼 이미지 생성 가이드

한 글에 들어가는 모든 이미지를 통일된 브랜드·에디토리얼 톤으로 유지하기 위한 규칙이다.

## 1. 공통 비주얼 언어
- **비율:** 16:9 와이드스크린 (`1376x768` 등 블로그 본문 최적화)
- **배경:** 깨끗한 오프화이트 (`#F8FAFC` / `#FFFFFF`), 넉넉한 여백
- **포인트 컬러:** 코발트 블루 (`#3182F6`), 시맨틱 보조색(성공 `#10B981`, 주의 `#EF4444`)
- **뉴트럴 톤:** 딥 차콜 텍스트 (`#191F28`), 쿨 그레이 (`#4E5968`, `#8B95A1`, `#E5E8EB`)
- **스타일:**
  - 커버(`01`): 미니멀 3D 아이소메트릭 일러스트 (매트 클레이/플라스틱 질감, 텍스트 없음)
  - 본문 다이어그램(`02`~`09`): 플랫 벡터 UI 카드, 부드러운 그림자, 날카로운 타이포그래피

## 2. 텍스트·라벨 규칙 (오타 방지)
- 이미지 안 텍스트는 **짧고 명확한 영문 UI 라벨·수치·코드**로 제한한다(예: `Before`, `After`, `4px`, `8px`, `Button`, `Input`, `variant="secondary"`, `Do / Don't`, `2.0 Days`, `0.5 Day`).
- 이미지에 들어가는 수치·토큰명·컴포넌트명은 본문 마크다운과 **100% 일치**시킨다.

## 3. 생성 및 저장 절차
1. 모든 이미지 브리프를 확정해 `image-generator` 서브에이전트를 **한 턴에 병렬 호출**한다.
2. **쿼터 제한(429) 폴백 전략:** 3D 커버 일러스트는 AI 이미지 생성기를 우선 사용하되, UI 다이어그램·비교 표·막대 그래프 생성 중 모델 쿼터가 소진되면 동일한 컬러 시스템(`#F8FAFC` / `#3182F6` / `#191F28`)과 `1376x768` 해상도의 HTML/CSS 카드를 헤드리스 Chrome/Edge(`--headless=new --screenshot`)로 렌더링해 오타 없는 고해상도 PNG를 확보한다. (Windows 한글 경로 이슈를 피하려면 ASCII 임시 경로에 스크린샷 저장 후 최종 폴더로 복사한다.)
3. 각 이미지 생성 완료 후 `read_file`로 직접 열어 오타, 잘림, UI 깨짐이 없는지 검수한다(결함이 있으면 해당 컷만 재생성).
4. 아티팩트 폴더의 `.jpg` 출력을 실제 PNG로 변환해 `<workspace>/images/01-<slug>.png` 순번 파일명으로 저장한다.

```powershell
Add-Type -AssemblyName System.Drawing
$img = [System.Drawing.Image]::FromFile($srcJpg)
$img.Save($dstPng, [System.Drawing.Imaging.ImageFormat]::Png)
$img.Dispose()
```
