# UX / 프로덕트 케이스 스터디 블로그 퍼블리셔

레퍼런스 조사부터 글 작성, 이미지 일괄 생성, 한국어 AI 윤문(`korean-humanizer`), 최종 검수 및 인라인 프리뷰까지 한 번에 완결하는 워크플로우다.

## 사전 확인 (요청이 모호할 때만)

주제·참고 요소·언어권이 명확하지 않으면 작업 전 2~3개 객관식 질문으로 먼저 좁힌다. 주제가 이미 명확하면 바로 1단계로 들어간다.

## 5단계 워크플로우

### 1단계: 레퍼런스 조사 및 원문 구조 파싱
- 검색으로 레퍼런스 후보를 찾되, **검색 요약의 추측 URL을 그대로 쓰지 않는다.**
- 모든 추천/참고 URL은 HTTP 200 응답과 실제 `<title>`을 확인한 뒤 제시한다.
- 사용자가 특정 레퍼런스 URL을 지정하면 HTML 본문을 직접 읽어 도입·문제·가설·전개·결과·마무리 구조와 문체(어미·호흡·각주·시각 자료 위치)를 추출한다.

### 2단계: 구조화 초안 작성 및 이미지 슬롯 설계
- [structure-template.md](./references/structure-template.md)의 6단 서사 구조(`도입 → 문제 → 가설(3원칙) → 1/2/3 핵심 실행 → 결과 → 적용해보기`)로 초안을 쓴다.
- 커버, 문제, 각 핵심 실행 소주제, 결과 등 시각화가 효과적인 지점에 구체적인 `[이미지 제안]`을 배치한다.

### 3단계: 통일된 톤의 이미지 병렬 생성·검수·저장
- [image-style-guide.md](./references/image-style-guide.md)의 스타일 가이드를 따라 `image-generator` 서브에이전트를 **병렬 호출**해 모든 이미지를 생성한다.
- **오타 방지:** 래스터 이미지 안 텍스트는 간결한 영문 UI 라벨·수치 위주로 설계한다.
- **육안 검수:** 생성된 모든 이미지를 `read_file`로 직접 열어 오타·깨짐·본문 수치 일치 여부를 확인한다.
- 아티팩트 디렉터리에 생성된 `.jpg` 파일을 실제 PNG 포맷으로 변환해 `<workspace>/images/01-<slug>.png` 형식으로 저장한다.

### 4단계: 마크다운 조립 및 `korean-humanizer` 윤문
- 초안의 `[이미지 제안]`을 상대 경로(`![설명](./images/01-<slug>.png)`)로 교체하고, 이미지 속 토큰·컴포넌트·수치와 본문 설명을 1:1로 맞춘다.
- `korean-humanizer` 스킬(`SKILL.md`)을 반드시 읽고 `트리아지 → 탐지(A~J, S1/S2/S3) → 윤문 → 감사 → 자가검증 6항 → 등급(A~D)` 절차를 그대로 실행한다.
  - S1 잔존 0건(`—`/`–`, 본문 연결어미 뒤 쉼표 `C-11`, `~한 것이다/것이죠` `I-1`, 막연한 긍정 마무리 `D-6`, 챗봇 잔재, 이모지 장식)을 확보한다.
  - 고유명사·수치·코드·직접 인용·이미지 링크는 100% 보존하고 변경률 30% 이하를 지킨다.
- 최종본을 `<workspace>/<slug>.md`로 저장한다.

### 5단계: 자동 검증 및 완성본 프리뷰
- [audit_and_preview.ps1](./scripts/audit_and_preview.ps1)을 실행해 아래 항목을 검증한다.
  1. 마크다운에 연결된 모든 `./images/*.png` 파일 실존 여부
  2. S1/S2 잔존 패턴 카운트 및 글자수(공백 포함/제외)
  3. `ORCA_CHAT_SCRATCH_DIR`가 설정된 경우 512 KB 이하 인라인 HTML 프리뷰 생성
- 인라인 프리뷰가 생성되면 `orca-chat-visuals` 규격에 맞춰 채팅에 `::orca-visual{file="<filename>.html" title="<제목>"}`로 바로 렌더링하고, 마크다운 파일과 이미지 경로를 링크로 안내한다.

## 완료 기준 (Done When)
- 추천/참고한 외부 URL이 모두 HTTP 200으로 검증됐다.
- `<workspace>/images/`의 모든 PNG가 육안 검수를 통과했고 마크다운에서 깨지지 않고 연결된다.
- `korean-humanizer` 감사에서 S1 잔존 0건, 등급 B 이상(권장 A)을 달성했다.
- 최종 마크다운 저장과(가능 시) 인라인 프리뷰 렌더링까지 마쳤다.
